## 技术教训
- **Vue ref 存对象返回 reactive 代理（2026-09-05 排查教训）**：`ref()` 深度响应，`.value` 存对象时读出的是 **reactive proxy**，与原始对象 `===` 恒为 false。长按拖拽里若用 `drag.value !== st` 判断「定时器是否过期」会永久拦截、导致拖拽永不激活。正确做法：给手势对象加自增 `seq` + `cancelled` 标记，定时器回调只认 `st.seq !== dragSeq || st.cancelled`，不要在定时器里对响应式 ref 值与原始对象做引用比较。
- **Tailwind v4 字号 token 必须用主变量 + 双连字符子属性（2026-09-05 全局修复）**：`src/style.css` 的 `@theme` 里若想自定义 `.text-名称` 字号工具类，正确写法是 **`--text-名称: 尺寸px`** 主变量，配 **`--text-名称--line-height` / `--text-名称--letter-spacing` / `--text-名称--font-weight`（双连字符）** 子属性；`--text-名称-size` 这类旧式拆分命名不会被 Tailwind v4 识别，`.text-*` 类**不会生成**、页面文字全部退化为默认字号（表现为「改字号没变化/标题按钮一样大」）。已于 2026-09-05 把 hero/display-lg/display-md/lead/lead-airy/tagline/body-strong/apple-body/caption/caption-strong/button-large/button-utility/fine-print/nav-link 全部改为正确写法并验证产物 CSS 含 `.text-*`。今后新增字号 token 务必按此格式。
- **npm12 安装带远程 tarball 依赖须加 `--allow-remote=all`（2026-09-05）**：本机 npm 12.0.2 默认禁用 `type:"remote"` 依赖（项目里 `xlsx` 恰好是 `https://cdn.sheetjs.com/...tgz`），直接 `npm install xxx` 会报 `EALLOWREMOTE`。须 `npm install <pkg> --allow-remote=all`。卸载同理。
- **抠图工具用 @imgly/background-removal 已否决（2026-09-05）**：曾评估做「上传图→去背景→下载PNG」工具并已安装 `@imgly/background-removal@1.7.0`，但该库打包体积过大（依赖 onnxruntime-web、protobufjs 等），未实现即放弃、依赖已卸载还原。**结论：图片分组暂不加抠图**；如未来再做，需先评估轻量替代（自托管模型/服务端抠图）。

- **新增工具三步（2026-09-05）**：① `src/data/tools.js` 的 `toolGroups` 加分组与工具（`{id,label,icon,tint}`，搜索/launcher 通过其派生的 `allTools` 自动命中）；② `views/tools/index.vue` 的 `toolLoaders` 加 `<id>: () => import('./components/XxxTool.vue')` 懒加载；③ 新组件需与其它工具一致：Teleport 到 body 的 fixed 弹窗壳 + `defineExpose({ open })`（launcher 靠 `toolRefs[id].open?.()` 唤起）。工具文件夹封面图传 `DesktopFolderTile` 的 `items` 用 `{key:id, icon}` 形态。
- **进制转换（2026-09-05）**：`network` 分组第二位应用 `baseConvert`（`BaseConvertTool.vue`）。二/八/十/十六进制互转：任一侧输入即实时联动；`input` 事件先按进制过滤非法字符再同步；解析用 `BigInt` 带前缀（2→`0b`、8→`0o`、16→`0x`，直接 `BigInt(clean)` 会按十进制解析出错）；输出十六进制统一大写；超长输入可用任意大整数。每框带复制按钮。注意工具放「网络」分组是用户明确指定。
- **中国传统色工具（2026-09-05）**：`color`（色卡）分组第二位应用 `chineseColors`（`ChineseColorsTool.vue`）。数据在 `src/data/chineseColors.js`（`chineseColorGroups` + `allChineseColors`），来源于开源 `zerosoul/chinese-colors`，9 大类 161 色（名称+HEX，无简介，勿手改）。组件支持分类 chips + 名称/HEX 搜索，点击色卡复制 HEX，文字颜色按亮度自适应黑/白。注意：**components 目录下的工具组件引用 src/data 需三级相对路径 `../../../data/`**（views/tools 下的 index 才是 `../../data/`）。
- **计算器（2026-09-05 终版交互）**：`finance`（财务）分组第二位应用 `calculator`（`CalculatorTool.vue`）。**上下两块显示屏**：上屏浅色条实时显示完整算式（`12 + 7`），下屏大号显示当前输入（输入中）或结果；**全程只记录算式 token、不提前算中间值**，按 = / Enter 时才对整条算式按四则优先级一次求值（×÷ 优先、同级左结合，如 `2 + 3 × 4 = 14`），结果继续按运算符则以结果续算（`14 × 2 = 28`），结果后直接输数字则另起新算式。等号后上屏保留 `算式 =` 历史、下屏出结果。内部运算符存 ASCII（求值用），展示经 `OP_LABEL` 映射为 `× ÷ −`。含 `%`（当前数÷100，作用于输入中或算式末数）、退格、C、`00` 键；末行布局 `00 0 . =`；两屏字号随长度自动收。支持键盘（0-9 . + - * / Enter/= Backspace Esc %）。除零显示「错误」并复位；结果经 `Math.round((v+EPS)*1e10)/1e10` 消浮点尾差。求值器：双栈 + `PREC` 优先级；以运算符结尾按 = 时重复左操作数。
- **网络分组「我的公网IP」（2026-09-05 两次迭代定稿）**：`toolGroups` 首位新增 `network` 分组，唯一应用 `publicIp`（`PublicIpTool.vue`）。归属数据源**主用 Vore API** `https://api.vore.top/api/IPdata`（中文省市库，对国内 IP 精确到地级市，实测安徽蚌埠正确；https+CORS 免鉴权、8s 超时；响应 `{ipinfo:{text,cnip}, ipdata:{info1:省,info2:市,info3:区,isp}}`），**兜底 ipwho.is**（MaxMind 国际库只准到省级——会把蚌埠归到合肥，故不作主源），IPv6 用 `https://api6.ipify.org?format=json`；两家都失败再回 `https://api.ipify.org` 仅拿 IP。展示字段：本机IP / 归属地 / 运营商 / 应用场景。Vore 路径：`cnip=true` → 归属=「中国 省 市[区]」、isp 直接中文（电信/联通/移动…）、isp 命中 `CN_CARRIERS(/电信|联通|移动|网通|铁通|广电/)` 时场景=家庭宽带；`cnip=false`（国外）→ info1..3 拼国家/州/城市、isp 留空不展示（该字段对国外不可靠）。ipwho 兜底路径保留 `REGION_CN` 省级映射 + `type`/ISP 启发式场景。IPv6 单独卡片展示，未检测到提示。纯 emoji 图标，无需 favicon。

- **惠普 support.hp.com（2026-09-05）**：脚本抓到的是反爬 HTML 拦截页误存成 `.ico`（损坏，manifest 引用后需删除换真图）。真图标与 `www.hp.com/favicon.ico` 一致（32×32 PNG 696B），从 `favicon.im/support.hp.com` 取得，现存 `favicon-support-hp-com.png`。教训：manifest 里若某图标「图片是 ico 但报损坏」，先看文件头是 `<!doctype html>` 即为拦截页，须删并换源。

## 交互架构
- **App 三 tab 左右滑动与内部长按拖拽的竞争仲裁（2026-09-05）**：`App.vue` viewport 用 pointer 手势做横滑切页；不能简单在子图标上 `stopPropagation` 挡 pointerdown（否则移动端从图标上滑不动、大片区域失效）。改为双事件仲裁：快速横滑 → App 锁定并 `window.dispatchEvent(new CustomEvent('site-swipe-lock',{detail:{pid}}))`，`views/sites/index.vue` 监听后放弃未激活的长按候选；静止长按到 0.38s → `views/sites/index.vue` `dispatchEvent(CustomEvent('site-sort-begin',{detail:{pid}}))`，App 监听后清掉本次 swipe。判定阈值：页面滑 4px/横向为主，tile 拖拽移动 10px 自我取消。`sites/index.vue` 拖拽定时器判断过期用 `st.cancelled || st.seq !== dragSeq`，**不得**用 `drag.value !== st` 比较（ref 深代理恒不等）。
