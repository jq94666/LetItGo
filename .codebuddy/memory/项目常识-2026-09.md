## 技术教训
- **Vue 3.5 watch 多源数组里的 ref-of-reactive 不再隐式 deep（2026-09-06 应用显隐排查教训）**：`watch([refA, refB], cb)` 中若 refB 的值是 reactive 数组且靠 `push/splice` 原地变更，**回调不会触发**（Vue 3.5.41 实测）——表现为 UI 响应完全正常（组件读取了该数组）但 watcher 静默失灵。必须显式 `watch([...], cb, { deep: true })`。settings store 持久化 watch 曾因此漏写 localStorage，纯代码审查发现不了，是浏览器冒烟测试暴露的。**凡是 watch ref 包裹的数组/对象，一律显式写 deep 与否，不依赖隐式行为。**
- **Vue ref 存对象返回 reactive 代理（2026-09-05 排查教训）**：`ref()` 深度响应，`.value` 存对象时读出的是 **reactive proxy**，与原始对象 `===` 恒为 false。长按拖拽里若用 `drag.value !== st` 判断「定时器是否过期」会永久拦截、导致拖拽永不激活。正确做法：给手势对象加自增 `seq` + `cancelled` 标记，定时器回调只认 `st.seq !== dragSeq || st.cancelled`，不要在定时器里对响应式 ref 值与原始对象做引用比较。
- **Tailwind v4 字号 token 必须用主变量 + 双连字符子属性（2026-09-05 全局修复）**：`src/style.css` 的 `@theme` 里若想自定义 `.text-名称` 字号工具类，正确写法是 **`--text-名称: 尺寸px`** 主变量，配 **`--text-名称--line-height` / `--text-名称--letter-spacing` / `--text-名称--font-weight`（双连字符）** 子属性；`--text-名称-size` 这类旧式拆分命名不会被 Tailwind v4 识别，`.text-*` 类**不会生成**、页面文字全部退化为默认字号（表现为「改字号没变化/标题按钮一样大」）。已于 2026-09-05 把 hero/display-lg/display-md/lead/lead-airy/tagline/body-strong/apple-body/caption/caption-strong/button-large/button-utility/fine-print/nav-link 全部改为正确写法并验证产物 CSS 含 `.text-*`。今后新增字号 token 务必按此格式。
- **npm12 安装带远程 tarball 依赖须加 `--allow-remote=all`（2026-09-05）**：本机 npm 12.0.2 默认禁用 `type:"remote"` 依赖（项目里 `xlsx` 恰好是 `https://cdn.sheetjs.com/...tgz`），直接 `npm install xxx` 会报 `EALLOWREMOTE`。须 `npm install <pkg> --allow-remote=all`。卸载同理。
- **抠图工具用 @imgly/background-removal 已否决（2026-09-05）**：曾评估做「上传图→去背景→下载PNG」工具并已安装 `@imgly/background-removal@1.7.0`，但该库打包体积过大（依赖 onnxruntime-web、protobufjs 等），未实现即放弃、依赖已卸载还原。**结论：图片分组暂不加抠图**；如未来再做，需先评估轻量替代（自托管模型/服务端抠图）。
