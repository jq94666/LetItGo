# 2026-09-03

## Word 提取页面工具（wordExtract）
在 `src/views/tools/components/WordExtractPagesTool.vue` 新增「Word提取页面」工具，已加入 Word 文件夹，支持上传 .docx/.doc 后按页码/页码范围提取页面导出新 .docx。

### 新增模块
- `src/utils/docxExtract.js`：docx 解析+分页+重建引擎。思路：拆分 w:body 为块（段落/表格/表格行），优先用 `w:br type=page`、`w:lastRenderedPageBreak`、非连续 sectPr 做真实分页；不足时用离屏 DOM（Measurer 类，批量插入一次性量高）按节页面宽度量块高后贪心切页。导出整体复用原 zip、只重写 word/document.xml，样式/编号/图片关系/页眉页脚全保留。
- `src/utils/legacyDoc.js`：旧版 .doc 尽力解析（OLE CFB + FIB + CLX piece table 还原文本，默认五号宋体量高估算），导出 .docx（用 docx 库）。注意 `.doc` 分页只是估算，UI 有提示。
- `src/utils/docPagination.js`：通用贪心分页 `paginateBlocks(blocks, sections, forcedBreaks)`。
- `src/utils/pageSpec.js`：页码表达式解析 `parsePageSpec`（支持 1,3,5-9、8-、all、中文逗号等）+ `formatPageRanges`。

### 交互细节
- 页面卡片可点击切换「此页前强制分页点」校正估算分页。
- 导出后自动触发下载并保留下载链接。

### 坑 / 约定
- `sectionMetrics(null)`（计算默认 A4 尺寸）曾因 `childEls(null)` 报 `firstChild of null`，务必对 null 做守卫（`childEls` 已加空值保护）。
- Vue 组件里 tools 弹窗统一 `defineExpose({ open })`，由 tools/index.vue 挂载并调用。
- 冒烟测试用过 Playwright 驱动真实浏览器（走 #/tools → Word 文件夹 → 上传 → 填页码 → 下载并校验 docx）；本地无 ms-playwright 浏览器，用系统 Chrome `executablePath`。测试脚本与 .tmp-smoke 已清理。

### 依赖
- package.json 显式新增 `jszip@^3.10.1`（npm install 受限无法联网时，node_modules 已有 3.10.1，且 package-lock.json 已手动补根依赖条目）。

## PDF 拆分工具（pdfSplit）
- `src/views/tools/components/PdfSplitTool.vue`：上传一个或多个 PDF → 输入页码/范围（复用 `src/utils/pageSpec.js`）→ 用 pdf-lib `copyPages` 提取后另存新 PDF。已加入 PDF 文件夹（图标 📑，文件夹现有 6 个工具）。
- 单选页时导出后自动下载，多文件/多结果时显示链接并支持「全部下载」。
- 坑：pdf-lib 页数是方法 `doc.getPageCount()`，**没有** `pageCount` 属性；校验输出 PDF 内容可用 `pdfjs-dist/legacy/build/pdf.mjs` 的 `getTextContent()`（Node 侧 import 该 legacy 入口可直接用，无需 worker）。
- 冒烟测试（已清理）：10 页 PDF 输入 `1,3-4,9-` → 输出 5 页且仅含标记 1,3,4,9,10；单选第 2 页 → 1 页。

## PDF 合并工具（pdfMerge）
- `src/views/tools/components/PdfMergeTool.vue`：上传多个 PDF（列表即合并顺序），支持上移/下移/置顶/置底调整顺序，用 pdf-lib `copyPages` 依序合并导出。已加入 PDF 文件夹（图标 📚，现共 7 个工具）。
- 合并按钮需 ≥2 个文件才可点；导出文件名 `${首个文件基名}等N个-合并M页.pdf`。
- 冒烟测试（已清理）：AAA(2页)+BBB(3页) 合并 → 5 页顺序正确；把 BBB 移到首位后再合并顺序正确。
