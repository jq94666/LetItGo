# 长期记忆（MEMORY.md）

## 用户偏好 / 协作约定
- **记忆归档规则（2026-09-05 起）**：只沉淀长期有效内容；**不创建每日日志**。`项目常识` 按知识形成月份拆到单独文件 `.codebuddy/memory/项目常识-YYYY-MM.md`（当前：`项目常识-2026-09.md`），本文件只保留跨月通用的「用户偏好 / 协作约定」。不写入一次性进展、临时调试信息。落笔前判断「半年后是否仍然成立」，否则不记。
- **临时文件一律直接删除（2026-09-03 再次确认）**：由我（AI）自己创建的临时/调试文件（如测试脚本 `.xxx-test.mjs`、诊断日志、`.tmp-*` 目录、启动的临时 dev/preview 进程等），清理时直接删除即可，不要询问或等批准。
- 涉及修改/删除**用户已有**文件、运行有副作用的命令（如 git push、安装全局包、删除仓库内既有文件）时，仍应先确认或走正常审批流程。
- **新增网站必须同步抓取 favicon**：在 `src/data/sites.js` 新增任何站点（含空文件夹首次加站点）后，运行 `npm run fetch:favicons`（`scripts/fetch-favicons.mjs` 读取 sites.js 自动下载图标并更新 `src/assets/icons/favicon-manifest.js`），否则页面会用首字母占位图标。favicon 按站点 `name` 作为 manifest 的 key，文件名按 `href` 域名生成（如 dbeaver.io → `favicon-dbeaver-io.png`）。
  - **增量抓取**：脚本已改为「已抓取过且本地图标文件仍在则跳过、不再重新下载」，只抓取新增站点。所以每次加网站跑一遍即可，不会重复下载旧图标。
  - **emoji 图标例外（2026-09-05）**：站点对象可带 `icon` 字段直接给 emoji 字符（如 `{ name: 'getemoji', href: '...', icon: '😋' }`），此时**不用抓 favicon**、渲染优先显示该 emoji（manifest 无需、也不该留该站条目；`fetch-favicons.mjs` 收集时按 `!s.icon` 跳过）。显示优先级：`icon`(emoji) > favicon > 首字母占位。
- **移动端主页搜索框布局（2026-09-05 定型）**：`views/home/index.vue` 移动端（≤767px）将搜索框放在底部「主页/网站/工具 + 设置」一排按钮的上方；左右边缘分别与主页按钮（tab pill 容器）和设置按钮对齐（与 `App.vue` 的 nav 用同一 `px-apple-md`），底部距导航约 16px。下拉在移动端**向上**展开（`bottom-full` + 6px 间隙），避免遮挡底部导航。桌面端保持原顶部居中布局不受影响。
