# 2026-09-02

## xlsx (SheetJS) 升级到 0.20.3
- 原 `npm install` 报 1 个 high 漏洞：`xlsx@0.18.5` 的 Prototype Pollution（GHSA-4r6h-8v6p-xvw6 / CVE-2024-22363）。npm registry 上的 `xlsx` 永远停在 0.18.5（SheetJS 已不再向 npm 发布），`npm audit fix` 无解。
- 本环境 npm 禁止远程拉包（`EALLOWREMOTE`：安装 `xlsx@https://cdn.sheetjs.com/...tgz` 被拒）。解决方式：**用 PowerShell `Invoke-WebRequest` 下载 `xlsx-0.20.3.tgz` 到仓库根目录，再 `npm install ./xlsx-0.20.3.tgz`**。
- 结果：`npm audit` → `found 0 vulnerabilities`。
- 依赖形式演变：先是用本地 tarball `file:xlsx-0.20.3.tgz`（绕过 EALLOWREMOTE），后又按用户要求改为官方 CDN 形式 `"xlsx": "https://cdn.sheetjs.com/xlsx-0.20.3/xlsx-0.20.3.tgz"`，并删除了仓库根目录的本地 tarball。
- 注意：本环境 npm 禁止远程拉包（`EALLOWREMOTE`），所以在本机执行 `npm install` 拉 CDN tarball 会失败；该 CDN 形式适用于允许远程拉包的环境。`node_modules` 里已是 0.20.3，故本地运行/构建不受影响。如需在本机离线复现，可重新下载 tarball 并改回 `file:` 形式。
- 组件 `src/views/tools/components/ExcelMergeTool.vue` 与 `PdfToExcelTool.vue` 本来就只用 `import * as XLSX from 'xlsx'` 的标准 API（read/sheet_to_json/book_new/aoa_to_sheet/write），0.20.3 完全兼容，无需改代码。
- 期间曾尝试改用 `exceljs`（registry 可用、无此漏洞），但用户明确要求回到 SheetJS 0.20.3，故已卸载 exceljs 并回退。
- 构建验证：`npm run build` 通过（268 modules）。

## 工具页新增「模拟」文件夹 + 模拟时钟（含置顶）
- 需求：工具页加文件夹「模拟」，应用「模拟时钟」——点击弹窗显示老式商务圆形模拟钟（秒针实时转动、与系统时间一致），并支持「固定到电脑屏幕最上层」。
- 实现方案：用 **Document Picture-in-Picture API**（`documentPictureInPicture.requestWindow()`，Chrome/Edge 116+）打开始终置顶小窗，实现「用其他办公软件也能看到时钟」。普通 web 页面无法靠 window.open 实现真正置顶，因此不支持 PiP 的浏览器给出提示（非兜底弹窗）。
- 新建 `src/views/tools/components/AnalogClock.vue`：SVG 圆形表盘 + 60 刻度 + 12 时标 + 时/分/秒针。**只使用内联样式（无 Tailwind/scoped），以便挂到 PiP 文档中不丢样式**。走时用 rAF 更新 `Date.now()`，角度含小数 → 秒针平滑扫动。
- 新建 `src/views/tools/components/AnalogClockTool.vue`：仿其他工具弹窗模式（`defineExpose({open})` + `<Teleport to="body">`）。置顶状态 `pinned/pipWindow/pipApp` 放**模块级**，切页后返回仍一致；组件卸载不自动取消固定（时钟可跨页继续置顶）。PiP 窗内 `createApp(AnalogClock,{size:'100%'})`，`disallowReturnToOpener:true` 只留时钟本体；用户关小窗触发 pagehide → 同步 `unpin()`。
- 注册于 `tools/index.vue`：group `{ id:'simulate', label:'模拟', tools:[{ id:'analogClock', ... icon:'🕰️', tint:'from-amber-400 to-orange-500' }] }` + toolComponents。`useDesktop` 的 order computed 会自动补入新 id，无需处理持久化。
- 置顶小窗交互演进（用户后续需求）：只显示圆形时钟、无网址/其他内容；新增 `FloatingClock.vue` 作 PiP 容器——鼠标悬停时右上角浮现 ✕ 关闭按钮，按住时钟用 `pipWindow.moveTo(screenX/screenY 增量)` 实现全屏任意拖动（配 pointer capture）。`AnalogClockTool.vue` 挂载由裸 `<AnalogClock>` 改为 `createApp(FloatingClock, { pipWindow })`。
- **「无方框」关键实测结论**：用户反馈固定后小窗显示 `localhost:5173` 且圆形时钟套在矩形深色框里。用真实 Chrome + Playwright 实测确认：(a) `localhost:5173` 是**浏览器自带的 PiP 来源提示条（浏览器 UI）**，不在网页 DOM 内（PiP DOM 只有数字与 ✕），网页代码无法移除，只能尽量 hover 不触发；(b) **Chrome 的 Document PiP 窗口支持透明背景**——把 html/body 设 `background:transparent` 后，用 PNG 解码检查角像素 alpha=0、表盘 alpha=255，证明可消除矩形框。据此把 PiP 窗口背景改为透明，时钟 SVG 本身四角即透明 → 悬浮窗只剩圆形时钟。
- 圆尺寸改为 `{ height:'100%', maxWidth:'100%', aspectRatio:'1' }`（始终正圆、不超出窗口不裁切）。build 通过。
- 用户为 Edge 151（Chromium 151，2026 新版）。确认该常驻来源条在最新内核下仍属浏览器 UI，网页无法隐藏/透明化 → **用户决定到此为止，接受浏览器自带提示条**，不再继续处理此话题。
- 构建通过。
- favicon 抓取脚本历次健壮性补强（`scripts/fetch-favicons.mjs` 的 `extFrom`）：先按字节魔数判断类型，已支持 JPEG/PNG/ICO/GIF/**BMP**，避免「URL 扩展名与实际内容不符」存坏图标；脚本增量抓取（已有文件跳过）。手动补图标时文件名按 hostname slug（如 icourse163-org）与清单条目需成对维护，后续跑 fetch 会按 prev 沿用不丢失。
