# Let It Go 随它导航
# 从何而来
每个程序员都有一个开源的梦想，我也不例外。在这行干了三年，深感能力不足，2020年6月转行，梦想藏在了心里。恰逢AI时代来临，Vibe Coding让我看到了完成梦想的曙光。
# 想做什么
工作中收藏了很多好的网站，我想把他们整理、记录、分享。

工作中有很多工具需求，以前分散在各个软件或网站上，我想把它们聚合到一处。

很多导航站点广告太多了，我想纯净搜索，一键直达官网。

# 到哪里去
持续收录优秀的网站、软件、资源。收录原则：免费或不免费但免费的部分足够满足用户需求。

持续开发优化工具和导航界面。优化速度取决于免费Token的额度，当月额度用完了，当月开发停止😂。
